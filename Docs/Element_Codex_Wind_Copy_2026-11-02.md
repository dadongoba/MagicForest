# 风图鉴：已装入文案

本稿经用户审核后装入Config/ForestElementCodex.json。每页独立描述同一种风的效果强度，再列四条常见用途；不新增实际物理机制。

### 风1 · 微风

空气轻轻流动，贴近皮肤才能觉出一点凉意。细绒毛微微颤动，垂着的细线偶尔晃一下，摊开的纸页仍安稳地留在桌上。它能带走手边的一点闷气，也能让淡淡的气味慢慢散开。

**常见用途**

- 散墨气——让刚写好的书页透透气，散去近处的墨味，不吹乱尚未装订的纸。
- 凉茶——轻轻拂过杯口，让热气缓缓散开。聊天可以继续，不必一直捧着茶吹。
- 传花香——把窗边花朵的香气带到屋里，闻得到，却不至于满屋都是。
- 拂绒毛——吹开粘在笔尖和细小零件上的浮绒，露出需要仔细查看的地方。

### 风2 · 轻风

脸上能清楚感觉到风，发梢和细草缓缓摆动。羽毛会在平整的桌面上挪动，纸角轻轻抬起，整张纸还不会被卷走。它足以让小片地方的空气流通，也能带走轻轻浮在表面的东西。

**常见用途**

- 透信袋——撑开空信袋，让里面积着的闷气散出去，装新信时不再带着一路的潮味。
- 凉点心——拂过刚出炉的点心，带走表面的热气，酥皮上的碎屑还能留得住。
- 清浮尘——吹去书架和工具架上的薄薄浮灰，省得擦过以后，灰又落回原处。
- 散草香——让晾着的香草透气，把气味带到附近。找草药时，鼻子也能帮上一点忙。

### 风3 · 和风

头发和衣角会随着风持续摆动，草叶朝着一个方向轻轻伏下。松放的薄纸容易翻页，绒絮离开地面后能飘出一小段距离。风能够穿过疏松的枝叶和晾开的织物，带走夹在其中的湿闷。

**常见用途**

- 晾信纸——让刚染过、已经沥水的纸张透气，配合温火慢慢干好。纸角要先压住，免得信还没写就出门了。
- 通药架——让风穿过疏放的草药，带走叶片之间的湿气，避免几层草叶一直闷在一起。
- 扬种绒——把带着绒毛的种子送离母株，让它们飘到附近空着的地方。
- 透斗篷——撑开赶路穿过的斗篷，让褶皱里的热气和潮气散开，下一程穿起来轻快些。

### 风4 · 清劲

宽大的叶片会翻动，松散的头发被吹向一边，挂起的衣物也能离开原处，鼓起又落下。地上的干叶会滑行、打转，薄纸若没有压好，很容易被带走。它能吹过一片工作场地，把轻薄的东西推向同一个方向。

**常见用途**

- 扬谷壳——把晒干的空壳和碎屑从籽粒间吹开，留下较沉的种子，方便收进袋里。
- 清石径——将干叶吹离窄窄的石板路，露出落叶下面的路面和台阶。
- 晾厚衣——让挂好的厚衣服充分展开，吹到贴在一起的衣褶，免得外面干了，里面还潮着。
- 助炉火——给已经燃起的小炉送入足够空气，让火烧得顺畅，适合准备一顿热饭。

### 风5 · 劲风

风吹在身上已有明显的推力，宽松的衣袖和裙摆会被撑起。灌木外层的细枝来回摆动，干叶能被卷离地面，薄布也会张成饱满的一片。轻巧的东西若有迎风的面，便能借这股力移动起来。

**常见用途**

- 升风筝——让风筝离开地面，在绳子牵引下稳稳张开。尾巴可以漂亮，线结还是得打牢。
- 扬小帆——撑起窄水面上轻舟的小帆，让船带着人和随身行李缓缓前进。
- 转风轮——带动屋旁的小风轮，为反复转动的轻巧装置出一份力。
- 清草场——把割下后晾干的碎草集中吹向场边，露出可以继续干活的空地。

### 风6 · 强风

迎着风走，衣服会紧贴身体，提着的大块布面也会明显拽手。灌木整丛摇动，地上的落叶和小枝容易一起被带走。帆面能够吃足风，风轮也能持续转动，适合带动已经装好、需要稳定出力的东西。

**常见用途**

- 送渡船——推动载着信件与行李的渡船走过平静水段，让传信人少划一阵桨。
- 鼓锻炉——为锻炉持续送风，配合足够的火，把炉里的铁料烧到能够加工的火候。
- 动磨轮——带动小型风磨处理晒干的谷物和草料，让手臂歇一歇，磨盘接着忙。
- 扬蓬布——撑开沉重的蓬布，把积在凹处的雨水抖落，重新张成可以遮雨的形状。

### 风7 · 疾风

风会扯动披风，吹得人需要站稳脚步。树上的小枝不断弯动，轻小的枯枝会在地上翻滚；宽大的帆和篷面则绷得很紧，连着的绳索也随之吃力。它足以带动较沉的负载，固定妥当的器具才能用好这股风。

**常见用途**

- 驱货舟——撑起货舟的帆，带动成捆木料或几箱物资，适合沿开阔水道运送。
- 转大磨——推动带着较重磨盘的风磨，处理整批需要磨碎的原料。
- 送长烟道——配合畅通的烟道，把长烟道中滞留的烟气送出去，为重新开炉做准备。
- 清枯枝——把空地上散落的小枯枝集中到边缘，方便捆扎、搬运和留作柴火。

### 风8 · 烈风

迎风行走已很费力，粗些的树枝会明显弯曲，松放的木桶、筐篮也可能被吹倒滚动。风掠过水面，会推起接连的波浪；大片帆布受到的拉力，足以拖动连在后面的重物。这股风适合在空旷处出力，需要结实的绳索和牢靠的支架。

**常见用途**

- 拖运木料——借牢固张开的风帆，拖动架在滑橇上的木料，运过平坦开阔的地面。
- 开积叶——吹开林道上堆得厚实的干叶与枯枝，让埋住的路面重新露出来。
- 驱重轮——推动承担重活的风轮，带动提水、碾压等需要持续用力的装置。
- 散浓烟——把空旷场地上积聚的浓烟迅速带离，让被烟遮住的地方重新看得清楚。

### 风9 · 狂风

风迎面压来，人很难站稳。树冠剧烈摆动，枯朽的枝条可能折断，未固定的木板和屋瓦也容易被掀起。地上的碎枝、落叶与尘土会成片移动，风已能改变一片场地的样子，适合清障和搬动成批的松散材料。

**常见用途**

- 清风倒场——把空地上纠缠堆积的断枝、干草吹向预留的收集处，方便之后集中搬走。
- 移沙堆——推动表层干燥、松散的积沙，露出被埋住的石面、沟口和旧路标。
- 动重帆——让专门加固的大帆带动沉重的运载装置，供宽阔地带的大宗运输使用。
- 剥旧篷——掀下废弃棚架上已经松脱的旧篷和破席。棚架得先清空，里面可不能还住着谁。

### 风10 · 暴风

风猛烈地扫过，足以折断粗枝，掀翻没有牢固固定的棚架，浅根或枯朽的树也可能倒下。大片杂物会被卷起、推走，迎风的宽大物体承受着沉重的力量。它能清开成片的障碍，也能驱动专为巨大风力建造的设施，作用的地方必须留出足够空间。

**常见用途**

- 开荒道——在划定的无人地带，清开纠缠成片的枯枝、倒木残梢和荒草，为重新修路腾出地方。
- 清废棚——拆除已经清空、准备废弃的轻型棚架，集中吹离残破的篷布与围席。
- 移积沙——推动大片松散的干沙，让久被掩埋的通道和石阶逐渐露出轮廓。
- 驱巨轮——为专门加固的大型风轮提供足够推力，带动整套提水或运输设施。这样大的活，总算不必全靠人拉。
