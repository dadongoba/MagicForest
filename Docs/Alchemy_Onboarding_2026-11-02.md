# 合成指引与今日大牌手札

## 玩家实际流程

进入夜间合成台后，滚动正文顶部显示“调配指引”。四步为选择委托、元素小物相加、大牌与排列顺序、检查与封瓶。第一次选择委托会进入第2步，首次投入素材进入第3步，首次出现封瓶确认进入第4步；也可主动前后翻看、收起和重新查看。它不强制指定配方，不阻止正常操作，不自动加入/移动/扣除任何物品。

合成台新增“当前试配”：显示当前排列最终留下的火/风/水、槽位用量、计划额度、药性绝对值总量及超过24的提醒。更换素材或顺序后随原刷新流程更新。这不是委托答案或评级，且不读取目标。原合成前的Comm.ElementRequest直接标准值展示移除，保留客人的愿望文字；交付后的目标/成品/偏离/推演仍按原结算页面显示。

教程解释两件任意火3可以合成火6；元素分别相加；火3→皇帝→火1为火7，火3→火1→皇帝为火8。说明大牌并非必用、素材免费但占槽、大牌及通用修饰合计5点额度、正负与零、药性总量24、二次确认扣料、三日结束流程。未给出客人应达到的数值。

## 今日大牌与书本入口

J打开的原书本增加固定分栏“元素效果 / 今日大牌”。原火/风/水三卷文字不变。今日大牌从UForestAlchemy::GetTodayMajors实时读取，按现有22张定义顺序排列同日仍持有的种类，同种牌合并目录并显示张数；不把没有抽到的牌冒充今日拥有。

每张显示名称、今日张数、每张1槽与实际Cost、通俗用法、一个当前运算器实际计算的示例、恶魔前缀下的行为、放置注意事项。副锅按实际代码的“素材份数”计锅长；太阳在主锅封蜡与副锅提前并回、并列选择顺序、向零取整、没有有效对象仍花额度等均写明。暂不支持嵌套副锅；本批没有扩展运算。没抽牌时显示获取提示，书页数据缺失时回退到原有牌面运算说明。

宽屏沿用左目录/右书页，窄屏沿用单页，今日牌目录置于正文上方；正文滚动，分栏与翻页/返回固定，不按整书缩小字体。左右键翻今日持有的种类；J/Esc或底部按钮合书。

合成台提供“查阅今日大牌”和“翻书 · 查看今日大牌用法”。打开时只隐藏原调配面板，保留委托、槽位、顺序、选中槽与确认状态；书合上后恢复原面板和UI焦点，不走会清空配方的OpenWorkbench。暂停期间调配面板仍在视口菜单状态中，避免误放行玩家输入。书本失败打开会立即恢复面板。背包处于“今日大牌”栏目时，页脚按钮直接打开大牌手札；元素小物栏目则直接打开元素效果。

## 数据与运算

新增Config/ForestMajorGuide.json，22条，字段id/howToUse/reverse/caution/example，以及介绍和共通规则。示例中fire:3/wind:2/water:1是虚拟输入，不使用或扣除背包物品；牌名、成本、类型和锅长从现有定义读取。没有LLM请求，没有读取任务目标或评分作为示例答案。

新增ForestAlchemyGuide.h/.cpp负责只读加载和示例说明。运算器原EvaluateAlchemySequence中的运算部分逐字提取为ComputeAlchemySequence，原评分部分保持不变。新PreviewAlchemySequence只返回药性与已生效额度，不需要委托；实际交付仍调用同一计算函数后做原评分。试配界面显示的计划额度沿用现有槽内成本总和，与封蜡后运算器不再计后续无效动作的已生效额度作区分。本批不改扣料、抽牌、换天、目标和评分公式。

Build.cs将ForestMajorGuide.json加入NonUFS分发。应用时需同时合并主模块源码、插件头/源、JSON并重新编译。保留现有书本动画与纸张/图标依赖，不新增或覆盖umap/uasset，无存档字段变化。不要把本增量当完整工程。
