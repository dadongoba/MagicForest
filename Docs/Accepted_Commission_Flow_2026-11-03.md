# 委托接取、手札与每日结束

## 本批实际接入

- 与 NPC 交谈时新增“接取今日委托”按钮。必须由玩家点击，不能让模型、物品展示或一句口头答应写入接取状态。同一委托重复点击不重复登记；正在生成回复或没有有效交谈对象时不能接取。
- 接取写入 `ForestDailyArcana` 存档，保存失败撤回接取。对话底部即时显示已接取状态，并说明回小屋合成，魔法书 J → “委托手札”随时查阅。
- 魔法书保留元素效果与今日大牌，另加独立“委托手札”栏目；仅列实际接过的委托、原有简短需求、日期、待合成/已结算状态及地点引导。不列未接取委托，不显示隐藏目标或内部底稿。
- 合成台只列今日已接取、未结算的委托。选择、投料、评估和最终封瓶均通过当前委托校验；不能依靠直接调用选择接口绕过接取。
- 展示物品保留既有交流用途，按钮改为“展示交流 · 不交付”，对话引导说明展示不完成任务。无物品赠送或交付操作加入 NPC 对话。
- 任务流程规则在 NPC 系统提示末尾覆盖旧“配好了拿来”的台词习惯，并提供程序确认的接取/完成状态。Forest 对话调用只追加最近八条角色消息，不再把同一段历史又嵌入 system。
- 每份委托封瓶评估、保存收据并确认结果后归档；头两份不换天。当天三位同伴的委托都有有效收据后，最后一份结算按钮才开始下一天；第三天三份结算后进入结局。
- “已结算”表示这份尝试已经评估并记录，不要求满分。低分、失败评级仍保留其后果，不把玩家锁在必须拿满分才能换天的循环中。原评分和目标没有改动。
- 原 `AdvanceDay` / `SetCurrentDay` / `ConfirmDryPotSynthesis` 等入口也需要原生收据所有者的完成许可。许可要求三份收据齐全且已持久化最终换天意图，旧蓝图不能在一份合成后提前换天。
- 结局回顾改为展示每天全部收据，避免只显示当天最后一份。

## 存档与失败恢复

接取新增数组字段，旧存档缺少时视为没有接取；已有有效收据视为对应委托已接取并结算，避免再次投料。收据还需日期与委托映射相符，并有有效评估。

不回退旧存档已经进入的日期或已经完成的旅程。旧版遗留的“单份收据待换天”在本日任务未齐时取消换天意图，保留结果供确认。最后一份沿用已有先保存换天意图、再确认日期、再归档的恢复路径，失败可重试，不重复扣料。

涉及存档应先备份 `Saved/SaveGames`；本批没有修改或删除用户现有存档。背包和炼药收据仍是原有分槽保存，突发进程退出时的跨槽原子性不是本批新解决的问题。
