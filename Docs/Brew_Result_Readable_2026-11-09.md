# 结算页：让目标、成品与偏离可读

本批只调整封瓶后的 Slate 结算界面。九份已审核委托的数值、结算揭示正文、评分公式、推演请求和换天规则不变；合成前仍不显示目标值。

## 玩家看到的顺序

1. 先看到本次判定及一句不带公式的原因。例如“方向大致对了，但成品整体作用太弱”。评级仍取自原评分器，不由界面重新判定。
2. 火、风、水各占一行：标准是该委托真正需要的效果，成品是封瓶后实际留下的效果；正值显示“增加”，负值显示“取走”，零显示“不改变”。每行显示两者相差几点，并用文字说明正好、偏弱、偏强、多余、缺失或方向相反。
3. 下方显示已审核的完整委托结算揭示，解释任务为什么需要这些元素及强度。只有收据目标与当前委托目标相同时才读取；旧收据或配置缺失时说明无法读取，不拿新底稿解释旧结果。
4. 原始总量、灵验度、非目标方向偏离、方向吻合、剂量比和评分器原文收进“查看判定详情”，默认折叠。右侧原推演文本和继续按钮保留。

例如标准火6、风0、水0，成品火4、风0、水2时，三行分别让玩家看出火少2点、风正好、水多出2点。完整揭示再说明火6为什么适合烘透炉壁，以及为什么不需要额外水分。这里的“点”指合成结果的元素作用强度，不是放了几件物品。

宽屏的数值说明列从约三分之一增至接近一半；窄屏仍纵向滚动。详细评分的展开状态只属于当前结算页，新收据默认收起，不写入存档。
