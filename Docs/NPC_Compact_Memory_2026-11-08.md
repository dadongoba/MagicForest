# NPC 轻量记忆接入：2026-11-08

基线：main 5bc2016，前置批次2026-11-07-06。用户已批准[轻量方案](NPC_Compact_Memory_Plan_2026-11-08.md)。本批没有修改人设、九份委托目标/叙事、图鉴、评分、三日流程、采集、地图或其他UI。

## 实际接入

- 继续使用DialogueMemoryLedger存档，SchemaVersion升级为2。每NPC一条80字进展摘要、最多12条60字玩家事实、4条活跃事项与最近4条结束记录，三NPC最多63条动态主记录；已披露编号与熟悉度仍使用现有权威记录，不另造一套。
- 旧记忆表行增加种类、最多40字短证据、事项说话人、任务归属和摘要原发生日。存档/角色/本地ID隔离，偏好称呼按固定槽更新；同一ID重放不重复应用。
- 现有意图分析读取有上限的当前NPC目录，选择最多4事实、2事项并提出至多一条玩家变化。生成和复核共用所选快照。玩家变化需现有回复复核独立认可、原话匹配且通过类型/长度/数值/归属检查；不能把猜测变成人物事实。
- 现有回复复核可附一条最后一句产生/结束的对话事项及短摘要；新NPC经历只记实际复核披露编号。最终通过、仍属当前回合且提交到交谈窗口后才应用NPC侧记忆。失败草稿、取消和过期回包不落NPC记忆。
- 关闭对话不再调用RequestSummary；原文History、Archived*、PendingTranscript与完整OfferText均为Transient，运行中的原话窗口最多8条，不继续写新存档。提出过的委托只留受限40字原文证据和批准事实编号，以便重进后承接，不伪造一段旧对话。
- 模型不能更改任务、熟悉度、地图、世界权威状态或配方目标。既有世界权威状态保留；没有把旧NPC推测世界表作为全员知识继续注入。本轮任务状态仍由原有实际动作收据提供，尚未接入的地图事件不因本批而自动成为NPC知识。
- 外部前回合记忆接口保留，只接收preferred_name/preference/self_report/request四类短文本，仍为Transient读取资料；不再接受任意嵌套JSON/目标向量或状态覆盖，不自动持久化外部资料。

## 迁移、容量与失败

- 旧存档熟悉度、秘密标记、任务和实际披露编号保留；旧自由摘要/模型事实没有可核对来源，不直接升级为新可信记忆。旧GameEvent事实和世界行保留。新模式拒绝旧的任意总结补丁接口，防止旁路重新写入自由人设/世界推测。
- Transient原文属性作为兼容字段保留，加载时不当作新长期记忆再保存；不从这些原文自动制造事实，也不建立永久聊天档案。玩家旧存档未在开发过程中被修改；迁移在应用后启动时执行。
- 已结束事项显式带状态，旧任务跨天标为过期/取消，不再混入活跃待办。满额只拒绝/替换具体普通行，不阻塞摘要、已有更新或权威记录。
- Working副本保存失败回滚；仅在内存保留每NPC最多3份已校验结构化补丁，后续本地持久化时重试并叠加最新权威进度，不保存原文重放队列。异常退出前尚未提取/保存的新信息仍可能丢失；未收录闲聊不承诺逐字回忆。
- 可选记忆字段无效不让本来合格的台词失败，也不单独触发AI修复请求；核心台词原有修复和45秒/6请求上限继续有效。
