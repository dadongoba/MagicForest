# 按界面尺寸绘制纸页背景 · 2026-10-28

采用公共 SForestPaperBorder 的原生 Slate 绘制，停止将 WoodlandPaper.png 直接用作纸页背景。原图文件保留供历史预览参考，元素图标继续使用原有素材。

背景重新设计为暖米色渐变纸张、轻微不规则褐色纸边、内侧阴影与橄榄绿植物细线。每次绘制都读取当前 FGeometry.GetLocalSize()，背景、边框和子内容使用同一局部坐标系；不混用屏幕物理像素与经过 DPI 的 Slate 单位。缩放和窗口变化由 Slate 提供的新尺寸驱动。

## 尺寸与内容安全区

| 界面 | 原有面板尺寸依据 | 新背景尺寸 |
| --- | --- | --- |
| 背包 | 940×600，经现有布局缩放 | 取实际分配的局部宽高 |
| 物品提示 | 宽 min(960, 可用宽−48)，高由换行内容决定 | 与纸页容器一致 |
| NPC 对话/寻找/引路 | 各模式宽高上限与可用宽高−48 | 与纸页容器一致 |
| 炼药台与结果 | 宽 min(1180, 可用宽−32)，高 min(740, 可用高−32) | 与纸页容器一致 |
| HUD 短纸条 | 文字所需尺寸加内容边距 | 与纸页容器一致 |

公共内容边距取左右至少16、上下至少14 Slate单位，原调用者的更大留白保留。窗口变化时重新设置的边距也应用此规则；外框和子内容裁剪限制在容器内。纸边内缩最多4单位；植物装饰仅在宽≥240、高≥100时绘制，限制在右侧文字安全区之外。短纸条省略植物装饰。没有用大图九宫格边角决定背景大小，也没有增加场景捕捉或图片加载。
