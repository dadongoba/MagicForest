# NPC agent 复核问题修复（2026-11-07）

基线：增量仓库 main `2c5c65c4f59d56f4fe405a299ef62df4a4445d50`，前置批次 2026-11-07-02。修改先在完整 Air 工程制作，再同步本次白名单；不打开编辑器。

## 修复行为

- **退出取消**：CancelNpcTurns 按值持有 Scope，在调用 HTTP/台词回调前置为取消。EndConversation 先保存局部引用、断开当前回合绑定，再取消。同步回调即使清空调用方引用或递归取消，也不会再访问空指针；ReplyGate 的完成幂等保持不变。
- **世界内台词**：实际游戏调用传入 internal_only 的 commission_state/action_receipt，角色只据此判断事件是否发生。共享 StateRules 区分未接、已接、已结算及本轮成功/失败；生成和语义复核区分事件权限与台词许可。新增 mechanism_language 拒绝“程序替你登记”等表达；普通工艺程序、合成台和魔法书说明仍可讲。不采用程序单词黑名单。
- **当面交付**：补上前半句否认原料交付、后半句却说“只收做好的成品”的矛盾反例。调配并封瓶后在合成台结算，不增加将成品、铁件当面交给 NPC 的环节。
- **配置失败**：MakeCommissions 检查审核配置应用结果，失败返回空列表并记录一次错误，不复活旧负值、风20、火11委托；错误解除后可再次记录新的故障。独立 RequestNpcDialogue 无有效委托时失败返回。公共 RequestWorldConsequence 的任务提示为空时同样返回 commission_missing，不发送空任务给模型；有效委托的原推演提示和流程不变。
- **内部约束隔离**：保持九份原始 target/purpose/topics/private_brief/settlement_reveal 不变，只调整派生事实元数据。接线员的“不能承诺新载具”及小说家的熟悉度管理条目改为 constraint；两条混合句拆开世界事实与菜单/叙事约束，内部部分不能被选为已讲事实或直接兜底。事实目录由270增至272条，源句仍能逐条核对。

人物背景、图鉴、数学、评分、三日推进、实际接取证据规则和记忆 Set/Get/Clear 接口保留。配置指纹变化会按既有机制重建披露编号账本，不清除熟悉度、任务接取和收据，不直接改玩家存档。
