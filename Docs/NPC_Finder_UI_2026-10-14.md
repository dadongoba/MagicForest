# 林间引路：NPC寻找三阶段界面与窗口自适应

批次 2026-10-14-08，基线 main 4d8b4ab，依赖纸页主题批次 2026-10-14-06/07。用户确认三阶段离线预览并要求尺寸自适应。本批将设计接入实际 Slate 源码。

## 交互和表现

1. V打开寻找：三个人物卡并排，带头像空框。点击人物只改变高亮，点击“选择带路的小物”才进入支付步骤；首次打开不预选人物。
2. 支付：三列格子替换下拉菜单，显示魔法小物真实名称、通用元素图标、属性与可读数量，右侧显示目标和物品描述。打开此步时清空选择、禁用确认；手动点物品后才能“交付1个并启程”。普通背包物品无元素记录时隐藏图标，不伪造属性。数量读取不可用时仅显示“可交付1个”，资格仍由原背包键值检查。
3. 移动：独立的头像空框/目标、叙事正文、已交付物品、WASD或Esc取消提示。仍接既有AI返回和失败回退，不修改提示词或接口。叙述变化时刷新，避免每帧重复读取背包和布局。

保留原有：可达性检查、只消耗1个、库存再次校验、缺少目标/断路退款、玩家主动取消不退款、抵达后交谈。仅通过代码差异核对，未做游戏内支付/退款操作验收。头像暂为代码绘制的空框，本批没有采集游戏截图。

## 自适应方式

实际 UUserWidget 根节点覆盖可用视口，预留24 Slate单位边距，SScaleBox 按宽和高的较小比例整体缩小，不放大超过设计尺寸，遵循既有引擎DPI比例。选人与支付居中，移动叙事与共用对话靠下。设计尺寸：选人960×500、交付960×540、移动860×310；共用对话760×540。

格子和物品详情可以滚动，确认/返回不在滚动区域内。缩小方式是保持桌面版布局比例，不是手机端单列重排；极小窗口下字也随面板缩小。本批没有改背包等其他界面的尺寸策略。
