# 右键观察与五秒空闲回正（2026-10-28）

- 右键按住拖动时独占观察角度；停止拖动并松开后保留当前方向。
- 连续五秒没有操作后平滑恢复组件初始 CameraYaw / CameraPitch。只恢复观察角度，滚轮缩放距离保留。
- 鼠标移动、按键、持续按住移动键/鼠标键都会重置计时；菜单或全图打开时暂停计时。再次操作会立即中断回正。
- 新增 CameraReturnIdleSeconds，默认 5 秒，可在组件 Camera 分类调整。
- 右键释放改用 Slate 实际鼠标状态检测，避免控制器输入在焦点/捕获切换时清空导致提前结束拖动。输入模式和光标只在状态切换时设置，取消逐帧强写光标。切出应用或打开菜单/全图会退出拖动。
