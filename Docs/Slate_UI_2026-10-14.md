# 森林手札 Slate UI 与自动追踪朝向

## 设计与实现

统一使用深墨绿、暖金、羊皮纸文字以及火/风/水元素色。
NPC 寻找、交谈、背包、采摘通知和采集 HUD 通过 UUserWidget 容器承载原生 Slate 控件。
寻找流程为角色卡片、明确选择物品、确认启程。背包为左侧物品列表和右侧详情。
保留 V/B/E/Enter/Esc 操作与原背包库存、扣费、退款逻辑。
旧采集计数字段隐藏，由新 Slate HUD 展示库存。炼药面板目前保留原蓝图布局，统一字体、底色和按钮状态；不是完整 Slate 布局重构。

自动寻找时，根据玩家实际 XY 速度计算 yaw，平滑更新玩家身体与控制器朝向；停止、取消或到达后不再修改朝向。不会让玩家朝 NPC 的最终位置直转而忽略道路弯曲。
